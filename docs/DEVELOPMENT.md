# Development

Replay and validation support Python 3.10–3.14 without PyTorch or Triton:

```bash
python -m pip install -e '.[dev]'
make validate
```

Validation runs syntax compilation, Ruff, tests that do not require a GPU,
import checks, semantic tests, and replay of both historical certificate
packets. It does not run a GPU or recollect historical evidence.

Focused checks are partial validation:

```bash
PYTHONPATH=src python -m pytest -q -m 'not gpu and not package'
PYTHONPATH=src python -m ruff check src evidence tests \
  --exclude tests/fixtures/external,evidence/results
PYTHONPATH=src python scripts/check_architecture.py
PYTHONPATH=src python -m daggertrace validate
```

## Ownership boundaries

Capture normalizes live AOT graphs; the model validates their structure and
identities; ownership analysis identifies borrowed writes and contribution
collapse. Target adapters select pinned source files, run numerical comparisons,
and check specialization settings. Certificate creation packages those records.

Generic replay independently validates and interprets the packet without importing
PyTorch/Triton, capture, target adapters, the model, or the ownership analyzer.
Certificate CLI replay also runs target-specific checks for supported examples
and rejects unsupported repositories.
Core/model/analyzer modules must not import CLI or target adapters. Target
support must not import routing/adapters, and one target family must not import
another. The small static architecture check also rejects top-level internal
cycles; it is not a dynamic dependency analysis.

Keep ownership analysis and replay independent. Similar code that separately
checks the same rule is intentional. Preserve aliases required by public APIs;
remove unused private aliases and unreachable branches.

## GPU and evidence changes

GPU checks require the exact [environment](ENVIRONMENT.md). External tests need
`DAGGERTRACE_LIGER_ROOT` or `DAGGERTRACE_ART_ROOT`; absent roots are reported as
skips. `make validate-gpu` also audits, replays and reproduces the selected target.
The default is Liger; supply its pinned root through `DAGGERTRACE_TARGET_ROOT`.

Do not rewrite the checked historical bundle to describe current code. Collect
new output separately, retain source/environment identity, and update owned
manifests with the existing generators when intentionally replacing evidence.
The bundle manifest is generated by `evidence/collect_manifest.py`.

Build a wheel and source distribution with `python scripts/build_dist.py`.
Source archives include the validation tree and exact `SOURCE_REVISION` marker;
wheels contain the runtime and necessary attribution resources. CI checks both.
